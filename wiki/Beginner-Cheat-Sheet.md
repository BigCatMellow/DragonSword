# Beginner Cheat Sheet

## Progression

**Hero level**
- Combat Texts
- don't grind random enemies
- level main 3 fairly evenly

**Breakthrough**
- raises level cap
- stuck at MAX? check this

**Skills**
- upgrade separately
- prioritize what you actually use

**Karma**
- major power system
- equip on all 3
- upgrade it

**Gear**
- decent gear + light upgrades early
- don't min-max yet

**Awakening**
- can change mechanics
- invest harder after choosing favorites

## Combat

Think:

**3 heroes = one combined moveset**

Basic loop:

**attack → condition/status → Signal → switch → Signal skill → next trigger**

Team goal:

**A triggers B → B triggers C**

White bar = Super Armor.

**Break → Signal/status chain → damage window**

## Exploration

Usually worth touching:

- waypoints
- dungeon entrances
- nearby puzzles
- chests
- treasure maps
- mounts/familiars

Something unreachable may need later traversal.

## If suddenly weak

Check:

**level → Breakthrough → Karma → skills → gear → team synergy**

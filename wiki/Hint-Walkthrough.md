# Hint Walkthrough

This is a **stuck guide**, not a step-by-step walkthrough.

## Use it like this

1. Open your chapter.
2. Read **Hint 1** only.
3. Still stuck? Open **Hint 2**.
4. Open **Answer** only when you want the solution.

If something feels broken rather than difficult:

1. reread current objective;
2. check elevation above/below you;
3. finish nearby combat;
4. interact again after objective/cutscene update;
5. check [[Stuck Index]].

# Beginner Cheat Sheet

Compact reference. Brevity over explanation.

## Core progression

**Hero level**
- use Combat Texts
- don't grind random enemies for XP
- level main 3 fairly evenly

**Breakthrough**
- raises level cap
- stuck at MAX? check this

**Skills**
- separate upgrades
- prioritize skills you actually use

**Karma**
- major power system
- equip on all 3
- upgrade it
- don't leave slots empty

**Gear**
- decent gear + light upgrades early
- don't min-max yet
- you'll replace it

**Awakening**
- can alter character mechanics
- invest harder once you know who you like

## Combat

Think:

**3 heroes = one combined moveset**

Don't stay on one character.

Basic loop:

```text
attack
→ cause condition/status
→ Signal activates
→ switch
→ Signal skill
→ trigger next character
```

### Signal Skills

Check each hero's Signal conditions.

Build teams where:

**A triggers B → B triggers C**

Common conditions include:

- Bleed
- Poison
- Airborne
- Knockdown
- Stun
- Break

### White bar

White bar = Super Armor.

General idea:

**break armor → status/signal chain → damage window**

### Useful trick

Start long attack → switch early.

Previous hero may keep finishing animation while new hero acts.

## Exploration

Usually worth touching:

- waypoints
- dungeon entrances
- nearby puzzles
- chests
- treasure maps
- mounts/familiars

Something unreachable may need a later traversal ability.

## Resources

Need upgrade item?

Check dungeon reward lists before wandering/grinding.

## Cooking

Not fluff.

Useful for:

- healing
- buffs
- damage
- revival

## If you suddenly feel weak

Check roughly:

**level → Breakthrough → Karma → skills → gear → team synergy**

## Early priority

1. main story / unlock systems
2. settle on 3 heroes
3. level them
4. understand Signal chain
5. equip Karma
6. upgrade useful skills
7. learn Break windows
8. unlock nearby travel/dungeons
9. collect exploration rewards
10. worry about serious gear optimization later

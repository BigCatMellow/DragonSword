# Hint-First Walkthrough

A **stuck guide**, not a step-by-step walkthrough.

Current research baseline: release build **1.0.6**.

## How to use

1. Find your chapter/problem.
2. Read **Hint 1** only.
3. Still stuck? Open **Hint 2**.
4. Open **Answer** only when you want the direct solution.

This keeps exploration and puzzle-solving intact while giving you somewhere reliable to look when the game stops communicating clearly.

## Hint levels

**Hint 1 — Nudge**  
Points attention in the right direction. Avoids telling you what to do.

**Hint 2 — Strong hint**  
Names the mechanic or object you should be thinking about.

**Answer — Direct**  
Exact action when you are done trying.

## What this guide avoids

- telling you every chest location;
- prescribing an “optimal” route;
- solving puzzles before you have a chance to notice their clues;
- spoiling later lore inside early chapter pages;
- pretending patch bugs are puzzles.

## If something feels broken

Before assuming puzzle failure:

1. check current objective text;
2. check above/below your elevation;
3. finish nearby combat;
4. interact again after a cutscene/objective update;
5. check [STUCK-INDEX.md](STUCK-INDEX.md);
6. only then consider a patch/progression bug.
